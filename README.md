# Kontr: Qumtepa

Brauzerda ishlaydigan 3D taktik shooter (Counter-Strike uslubida). O‘rnatish shart emas — havolani oching va o‘ynang.

## O‘ynash

GitHub Pages yoqilgandan keyin: `https://<foydalanuvchi>.github.io/<repo>/`

Mahalliy ishga tushirish: `index.html` faylini Chrome yoki Edge’da oching (internet kerak — Three.js va shriftlar CDN’dan yuklanadi).

## Imkoniyatlar

- 4 xarita: Qumtepa, Eskishahar, Ombor, Qorliq
- Ittifoqchi va raqib botlar soni (har jamoada 10 tagacha), 3 xil qiyinlik
- Raundlar, iqtisod, xarid menyusi (B), qurol olish/almashtirish (E), tashlash (G)
- CS2 uslubidagi spray naqshlari, bunnyhop va air strafe, km/soat ko‘rsatkichi
- Sozlanadigan pritsel (rang, uzunlik, qalinlik, oraliq, kontur, nuqta, T-shakl, ulashish kodi)
